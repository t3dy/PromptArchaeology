20 Questions on MTGSLIDER

Coach offerings grounded in what your prompt corpus actually says about this project. Pull one at random; or read in order if you feel like company. None require an answer.

  1. Your 2026-02-23 Scryfall+slideshow prompt is the genesis of MTGSLIDER. Have you re-read it lately? It's clearer than your current README.

  2. You said in 2026-02-25: "LLMs are so bad at giving advice about Magic the Gathering." What context does an LLM specifically need to give good MTG advice — and which of those contexts is MTGSLIDER already providing?

  3. Your 2026-02-27 prompt described MTGSLIDER's first concrete win — building a winrate-driven Scryfall slideshow tool before Claude Code existed. What's the equivalent next "small concrete win" with the tool you have now?

  4. You wrote about 17lands data, win rates, and Scryfall API as your three primary inputs. Are those still the three? Has anything been added without your explicitly noticing?

  5. The phrase "goofy decks" appears in your prompts as far back as 2016 (Rubinia Soulsinger EDH). Is there a goofy-deck deck in MTGSLIDER's output — or is it all serious archetypes?

  6. You imagined this as a tool for MTG content creators. Name the three creators you most want to send a deck to. (Not as a goal — as a prompt for taste calibration.)

  7. The alchemy / hermetic / esoteric layer is what makes MTGSLIDER yours and not a generic deck builder. Which themes have you parked that you most miss?

  8. "Ten Cards, Ten Histories" was a project idea earlier in our conversation. Which ten cards would they be, in priority order, off the top of your head?

  9. The Scryfall + alchemy_scryfall DB connection: have you actually run a join across them? The infrastructure is there. The query is one line.

  10. If you had to pick the single best deck of the 98 for an external eye, which one comes to mind first? That answer matters.

  11. The per-query log convention started here. Has it served you well, or has it become noise? Your honest answer changes how the tool should evolve.

  12. "Limited Level-Ups," "Sierkovitz," "Rhystic Studies" — three creator voices you've cited in prompts. Which would actually open a deck if you DM'd it? (Don't DM. Just notice the answer.)

  13. The etymology data in MTGSLIDER is unverified at the source. What would change if every etymology had a verified_by_ted boolean? (You don't have to add it. Just notice what changes.)

  14. 17lands data is freely available. Scryfall API is freely available. You're not gated by data; you're gated by attention. What's the smallest thing you could do tonight that consumes no new data and produces one improvement?

  15. Among your prompts about MTG, the most-frustrated cluster is around table layout (the scroll-bar saga of 2024-10). Has MTGSLIDER inherited any of that frustration, or did the table-design exercise resolve it?

  16. The MTGSLIDER GitHub repo is live. Do you remember the specific moment you decided to push it? That moment matters as a precedent.

  17. Etymology + card art + historical magic — that triplet is your signature. What domain outside MTG would benefit from the same triplet? (You once mentioned Pokémon, Yu-Gi-Oh, baseball cards in passing. Not all triplets transfer; some do.)

  18. Which deck in MTGSLIDER's output would you want to be remembered by if MTGSLIDER stopped today? That's the deck to polish next.

  19. PARKING_LOT.md has 30+ entries. Of those, which one would you pick first if you only had Saturday morning to work on slice 2?

  20. If you wrote a 600-word piece titled "Why I Built MTGSLIDER", what would the first sentence be? Just the first sentence. The rest would follow.

Pick one. Or none. The corpus knows you've already thought about each of these — the question is which one wants air today.
