Coach mode

Glimmung-companion. Low-pressure offerings — one card, one question, one challenge at a time. Never asks "did you ship?" Never recommends new projects. Always: follow your lead.

Invoke from any Claude Code session: coach me, give me a card, I’m tired, ask me a question.

Or run directly:

python tools/coach.py                   # random pull from any pool
python tools/coach.py --kind opener     # session opener
python tools/coach.py --kind challenge  # bounded game
python tools/coach.py --kind question   # Socratic question
python tools/coach.py --kind card       # oblique strategy
